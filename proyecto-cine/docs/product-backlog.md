# Product Backlog
## Plataforma de cine para pequeños cineastas

**Objetivo del producto:** permitir que nuevos y pequeños cineastas publiquen sus producciones, ganen visibilidad y puedan darse a conocer ante una audiencia.

**Flujo mínimo recomendado (MVP):**
registro → perfil → publicación → descubrimiento → visualización → interacción → estadísticas

Prioridad: **Alta** (necesario para el MVP) · **Media** (mejora la experiencia post-MVP) · **Baja** (valor agregado / administración)
