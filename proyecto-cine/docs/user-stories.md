# User Stories
## Plataforma de cine para pequeños cineastas

**Objetivo:** permitir que nuevos y pequeños cineastas publiquen sus producciones, ganen visibilidad y puedan darse a conocer ante una audiencia.

---

## Épica 1: Gestión de cineastas

### Feature 1.1: Registro de cineastas
- Como cineasta, quiero registrarme en la plataforma para crear una cuenta.
- Como cineasta, quiero ingresar mis datos personales para completar mi registro.
- Como cineasta, quiero recibir confirmación de mi registro para saber que mi cuenta fue creada correctamente.

### Feature 1.2: Inicio de sesión
- Como cineasta, quiero iniciar sesión con mis credenciales para acceder a mi cuenta.
- Como usuario, quiero cerrar sesión para proteger mi cuenta cuando termine de utilizar la plataforma.

### Feature 1.3: Perfil del cineasta
- Como cineasta, quiero crear mi perfil para dar a conocer quién soy.
- Como cineasta, quiero agregar una descripción sobre mí para que los espectadores conozcan mi trayectoria.
- Como cineasta, quiero editar la información de mi perfil para mantenerla actualizada.
- Como espectador, quiero consultar el perfil de un cineasta para conocer sus producciones.

---

## Épica 2: Gestión de contenido audiovisual

### Feature 2.1: Publicación de producciones
- Como cineasta, quiero subir un video para publicar mi producción en la plataforma.
- Como cineasta, quiero agregar un título a mi producción para identificarla.
- Como cineasta, quiero agregar una descripción a mi producción para explicar de qué trata.
- Como cineasta, quiero seleccionar el género de mi producción para facilitar su clasificación.
- Como cineasta, quiero agregar una imagen de portada para presentar visualmente mi producción.

### Feature 2.2: Administración de producciones
- Como cineasta, quiero consultar los videos que he publicado para administrar mi contenido.
- Como cineasta, quiero editar la información de una producción para corregir o actualizar sus datos.
- Como cineasta, quiero eliminar una producción para retirar contenido que ya no deseo publicar.
- Como cineasta, quiero conocer la cantidad de producciones que he publicado para llevar un control de mi contenido.

---

## Épica 3: Descubrimiento de contenido

### Feature 3.1: Búsqueda
- Como espectador, quiero buscar una producción por su nombre para encontrarla fácilmente.
- Como espectador, quiero buscar un cineasta por su nombre para encontrar su perfil.
- Como espectador, quiero buscar producciones por género para encontrar contenido de mi interés.

### Feature 3.2: Filtrado y exploración
- Como espectador, quiero filtrar las producciones por categoría para encontrar contenido específico.
- Como espectador, quiero consultar las producciones más recientes para descubrir nuevos trabajos.
- Como espectador, quiero explorar diferentes cineastas para conocer nuevos talentos.

---

## Épica 4: Visualización de contenido

### Feature 4.1: Reproducción
- Como espectador, quiero reproducir una producción para poder verla.
- Como espectador, quiero pausar y reanudar una producción para controlar mi reproducción.
- Como espectador, quiero controlar el volumen para adaptar el sonido a mis preferencias.
- Como espectador, quiero conocer la duración de una producción antes de reproducirla.

### Feature 4.2: Información de la producción
- Como espectador, quiero consultar la descripción de una producción para conocer su contenido.
- Como espectador, quiero consultar el perfil del cineasta desde su producción para conocer quién la creó.
- Como espectador, quiero conocer el género de una producción para saber qué tipo de contenido voy a visualizar.

---

## Épica 5: Interacción de la comunidad

### Feature 5.1: Me gusta
- Como espectador, quiero darle "Me gusta" a una producción para expresar que me agradó.
- Como espectador, quiero quitar mi "Me gusta" para modificar mi interacción con una producción.
- Como cineasta, quiero conocer la cantidad de "Me gusta" de mi producción para conocer la respuesta de los espectadores.

### Feature 5.2: Comentarios
- Como espectador, quiero comentar una producción para expresar mi opinión.
- Como espectador, quiero consultar los comentarios de una producción para conocer las opiniones de otros usuarios.
- Como cineasta, quiero consultar los comentarios de mis producciones para conocer las opiniones de los espectadores.

### Feature 5.3: Favoritos y compartir
- Como espectador, quiero guardar una producción en favoritos para verla posteriormente.
- Como espectador, quiero consultar mis producciones favoritas para acceder nuevamente a ellas.
- Como espectador, quiero compartir una producción para darla a conocer a otras personas.

---

## Épica 6: Estadísticas para cineastas

### Feature 6.1: Estadísticas de reproducciones
- Como cineasta, quiero conocer la cantidad de reproducciones de mis producciones para saber cuántas personas las han visto.
- Como cineasta, quiero consultar las reproducciones de cada producción para conocer cuál ha tenido mayor alcance.

### Feature 6.2: Estadísticas de interacción
- Como cineasta, quiero conocer la cantidad de "Me gusta" de mis producciones para conocer la reacción de los espectadores.
- Como cineasta, quiero conocer la cantidad de comentarios de mis producciones para medir la interacción de la comunidad.

### Feature 6.3: Seguidores
- Como cineasta, quiero conocer cuántas personas siguen mi perfil para conocer el crecimiento de mi audiencia.
- Como cineasta, quiero consultar el crecimiento de mis seguidores para conocer la evolución de mi audiencia.

---

## Épica 7: Promoción y visibilidad

### Feature 7.1: Contenido destacado
- Como cineasta, quiero que mis producciones puedan aparecer como contenido destacado para aumentar su visibilidad.
- Como espectador, quiero consultar contenido destacado para descubrir producciones de nuevos cineastas.

### Feature 7.2: Nuevos talentos
- Como espectador, quiero consultar una sección de nuevos cineastas para descubrir talentos emergentes.
- Como cineasta, quiero aparecer en la sección de nuevos talentos para dar a conocer mi trabajo.

### Feature 7.3: Recomendaciones
- Como espectador, quiero recibir recomendaciones de producciones para descubrir contenido que pueda interesarme.
- Como espectador, quiero recibir recomendaciones de cineastas para descubrir nuevos creadores.

### Feature 7.4: Promoción de producciones
- Como cineasta, quiero compartir mi producción para aumentar su alcance fuera de la plataforma.
- Como cineasta, quiero conocer el alcance de mi contenido promocionado para saber cuántas personas lo han visto.

---

## Épica 8: Administración y moderación

### Feature 8.1: Gestión de usuarios
- Como administrador, quiero consultar los usuarios registrados para administrar la plataforma.
- Como administrador, quiero bloquear un usuario para impedir que utilice la plataforma cuando incumpla las normas.
- Como administrador, quiero desbloquear un usuario para permitir nuevamente su acceso.

### Feature 8.2: Moderación de contenido
- Como administrador, quiero consultar las producciones publicadas para verificar que cumplan las normas.
- Como administrador, quiero eliminar una producción que incumpla las normas de la plataforma.
- Como administrador, quiero revisar contenido reportado para determinar si requiere alguna acción.

### Feature 8.3: Moderación de comentarios
- Como administrador, quiero revisar comentarios reportados para identificar contenido inapropiado.
- Como administrador, quiero eliminar comentarios que incumplan las normas de la plataforma.
